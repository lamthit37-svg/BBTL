## 2. Phạm vi và bằng chứng gốc

- Cửa sổ (`windows.tsv`): NewNpcChat 576, Quest 38, MissionReply 20, QuestLog 97, MissionTrack 241, ScrollInfo 82.
- Gói gốc: `CGExecuteScript` opcode 2219; `Send_XSCRIPT` Game.exe `0x1402411a0` (đóng bản ghi 128 byte ở CDataPool
  `+0x138dc`), `Set_XSCRIPT_ScriptID 0x140241560`, `_Function_Name 0x140241400`, `_ParamCount 0x140241630`,
  `_Parameter 0x140241360`, `Clear_XSCRIPT 0x140241170` (ghi trong `src/client/face/ui/script/xscript.hpp`). Protocol của dự
  án chưa có tin này: thêm vào catalog (tệp chung với M, theo khoá). Tin `UI_COMMAND`: đọc handler gốc bằng REA trước khi viết.
- Server (N): `src/server/talk/**`, `mission/**`, `ops/**`, bảng `dev/server/tables/server/{talk_*,mission_*}.tsv`. Chuỗi tân thủ
  theo `docs/NHIEM-VU-NGUON.md` mục 5 và 9; script client `src/client/script/Config/event/dali/edali_newquest_*.lua`.
- Client (N): `npc_talk.*`, `quest_log.*` và hàm `Talk:*`, nhiệm vụ, `Send_XSCRIPT`, nhận `UI_COMMAND`. Hai cửa sổ viết
  tay so với bản script theo mục 2 của `HO-SO.md`, giữ bản tốt hơn kèm số đo (`THIENLONG_UI_SCRIPT=<tên>` của hud.cpp để so;
  cửa sổ chạy script thêm vào `kScripted`).
- Máy chủ (M, khoá): lệnh `teleport`, `ui_command`, `signpost` ở `play`; B1 khung lớn bị bỏ lặng (`gate/table.cpp`).
