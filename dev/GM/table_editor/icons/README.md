# Biểu tượng Lucide

- Phiên bản: Lucide 1.58.0
- Nguồn: https://github.com/lucide-icons/lucide/releases/download/1.58.0/lucide-icons-1.58.0.zip
- SHA-256 của zip (khớp digest GitHub release): b8ef0e89a3a26d96ef43fabb3c55ace846236cd09439b15c2dac6ea450524e55
- Giấy phép: ISC, xem tệp LICENSE (lấy từ thẻ 1.58.0 của kho lucide-icons/lucide).
- Chỉ chép các biểu tượng app dùng, không sửa nội dung SVG. main.py thay `currentColor` bằng màu chữ của palette lúc nạp
  và vẽ bằng QtSvg của PySide6.

Biểu tượng dùng: refresh-cw, search, file-output, save, undo-2, redo-2, list-plus, list-minus, folder, folder-open,
table, lock, triangle-alert, info.
